## 为什么把博客后端从 PostgreSQL 迁移到 Markdown

运维数据库是一件很烦的事情。备份、迁移、升级、连接池、磁盘满了……对于一个个人博客来说，这一切都太重了。

### Markdown 文件的优势

- **版本控制**：Git 天然支持，每次修改都有记录
- **零运维**：文件系统不需要维护，不会宕机
- **可移植**：换个静态站点生成器，文章照样能用
- **编辑器自由**：VS Code、Obsidian、甚至手机备忘录都能写

### 代价是什么

- 没有实时搜索（可以用 Pagefind 在构建时生成索引）
- 没有管理后台（说实话个人博客也不需要）
- 发布流程多一步 git push（但 GitHub Action 自动化了）

总的来说，对于个人博客，Markdown 文件比数据库更合适。
